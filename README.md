Tarkov Gear Store (FastAPI SSR)

Реалізація маркетплейсу спорядження на базі FastAPI з рендерингом серверних шаблонів (SSR), обробкою медіафайлів та прямими SQL-запитами.

### 🛠 Стек технологій
- **Фреймворк:** FastAPI, Uvicorn, Starlette SessionMiddleware
- **Робота з даними:** SQLite3 (сирі параметризовані SQL-запити)
- **Обробка медіа:** Pillow (PIL) — стиснення та генерація прев'ю на льоту
- **Шаблонізатор:** Jinja2 (HTML-форми, flash-повідомлення)

### ⚙️ Реалізований функціонал
- **Серверний рендеринг (SSR):** повноцінний вебдодаток з авторизацією через кукі-сесії та передачею ролей (`admin` / `user`).
- **Контроль доступу:** використання механізму Dependency Injection (`Depends(admin_required)`) для захисту адмін-роутів.
- **Обробка та оптимізація зображень:**
  - Санітизація імен завантажуваних файлів регулярними виразами для захисту від Path Traversal.
  - Автоматичний ресайз картинок товарів до 300x300 px засобами Pillow.
- **Складні SQL-запити:**
  - Формування зведеного звіту замовлень через оператор `COALESCE` для об'єднання товарів різного типу в єдину видачу.
  - Захист від SQL-ін'єкцій через параметризацію запитів.
