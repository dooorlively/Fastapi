Marketplace Web Application ([Fastapi)
Навчальний маркетплейс із єдиною базою даних для вебінтерфейсу та Telegram-бота. Проєкт розроблено для відпрацювання бізнес-логіки інтернет-магазину та синхронізації даних між різними платформами.

Стек технологій
Мова: Python 3
Бекенд: [Fastapi]
Бот: Telegram Bot API (aiogram / telebot)
База даних: SQLite
Медіа: робота зі статичними файлами та завантаженням зображень (медіафайли товарів)
Реалізований функціонал:
Інтеграція з Telegram-ботом:
Спільна база даних для сайту та бота: клієнт бачить ідентичну історію замовлень та статус покупок на обох платформах.
Рольова модель (RBAC):
Клієнт: перегляд каталогу товарів із зображеннями, оформлення замовлення, перегляд особистої історії транзакцій.
Адміністратор: повноцінне керування асортиментом (додавання нових лотів із фотографіями, редагування цін/описів, списання/видалення).
Складський облік: динамічний поштучний контроль залишків на складі при оформленні замовлення та надходженні нового завозу.
Обробка медіафайлів: валідація, завантаження та відображення картинок товарів у каталозі.
